# DStarix Internship Guide RAG Chatbot

A Retrieval-Augmented Generation (RAG) chatbot built using LangChain and Groq to answer questions based on the DStarix Internship Rule Book.

## Features

- Retrieval-Augmented Generation (RAG)
- LangChain
- FAISS Vector Database
- Groq LLM
- Streamlit Interface
- CLI Interface
